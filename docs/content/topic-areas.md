## 선정 기준
- 최소 3개 토픽 영역에서 선정 (다양성 확보)
- 동일 출처 기사 2건 초과 금지 (편향 방지)
- 7일 이내 발행 기사 우선
- 조회수·사회적 이슈 반영 (Claude API 점수화)
- 최종 12개 + 여분 3개 (관리자 교체용)

| 번호 | 테마명 | 분야 구분 | 보고서 구성 |

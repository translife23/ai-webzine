# 핵심 원칙 (불변)

1. **맥락 유지**: 세션이 끊겨도 PENDING.md와 DONE.md로 결정 맥락을 유지한다.
2. **1결정 1커밋**: 결정 1건은 반드시 커밋 1개로 반영한다.
3. **관리자 승인 우선**: 자동화는 관리자 승인 없이 최종 발행하지 않는다.
4. **무결성 보호**: NEVER TOUCH 목록 파일은 pre-commit hook으로 보호한다.
5. **원자성 보장**: 웹진 배포 실패 시 뉴스레터 발송하지 않는다.
6. **PC 독립 운영**: 모든 자동화는 클라우드(Routines, Render)에서 실행되어 로컬 PC에 의존하지 않는다.

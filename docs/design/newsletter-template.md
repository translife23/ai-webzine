## 이메일 섹션 구조
1. **헤더 배너** — 로고, 웹진명, 호수, 발행일 (파란색 배경)
2. **기획 보고서 요약** — 제목, 핵심 포인트 3줄, "자세히 보기" 버튼 (2개)
3. **구분선**
4. **주요 뉴스 12선** — 각 기사: 토픽 태그 + 제목 + 1줄 요약 + 출처·날짜 + 링크
   - 2열 그리드 (모바일: 1열)
5. **푸터** — 웹진 링크, 구독 취소 링크, 저작권

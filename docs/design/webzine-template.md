## 타이포그래피
- 폰트: Pretendard (한국어), system-ui (폴백)
- 제목(h1): 32px / 700 weight
- 섹션 제목(h2): 24px / 700 weight
- 카드 제목(h3): 18px / 600 weight
- 본문: 16px / 400 weight / line-height 1.7
- 보조 텍스트: 14px / 400 weight
- 태그: 12px / 600 weight

## 레이아웃
- 최대 너비: 1200px (중앙 정렬)
- 컨테이너 패딩: 24px (모바일: 16px)
- 카드 그리드: 3열 (태블릿: 2열, 모바일: 1열)
- 카드 간격: 24px
- 카드 패딩: 20px
- 카드 radius: 12px
- 카드 그림자: `0 1px 3px rgba(0,0,0,.08), 0 4px 12px rgba(0,0,0,.04)`
- 카드 호버 그림자: `0 4px 16px rgba(0,0,0,.12)`

## 페이지 섹션 구조 (각 호)
1. 헤더 — 웹진명, 호수, 발행일
2. 기획 보고서 1 (기술 분야) — 5단 구조 접기/펼치기
3. 기획 보고서 2 (비기술 분야) — 동일
4. 이번 주 AI 주요 뉴스 12선 — 카드 그리드, 토픽 태그 색상 구분
5. 아카이브 링크
6. 푸터 — 구독 안내, 저작권

## 헤더 디자인
- 좌: 웹진 로고/타이틀
- 우: 호수 배지, 발행일
- 배경: 그라디언트 (primary → primary-dark)
- 텍스트: 흰색

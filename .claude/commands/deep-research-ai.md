# /deep-research-ai

AI 웹진 기획 보고서를 5단 구조로 작성하는 Deep Research 슬래시 커맨드.

## 사용법
```
/deep-research-ai [주제] [분야]
```

## 동작
아래 프롬프트를 사용하여 웹 검색 기반 심층 리서치를 수행하고 Markdown 보고서를 생성한다.

- 통계 수치 및 출처 명시

- 현재 시점에서 이 주제가 부각되는 맥락
- 미디어 노출 현황 및 사회적 관심 배경

### 중기 전망 (1~3년)
